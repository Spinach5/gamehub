# gameHub 多语言（i18n）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 gameHub 加入简体中文 / English 双语界面，语言可在设置中切换并持久化，新增语言只需一个 JSON 文件加一行注册。

**Architecture:** `crates/ui` 内建 i18n 模块：`Language` 注册表 + `include_str!` 嵌入的 JSON 目录，`tr` / `tr_args` / `tr_plural` 查找并回退；`SettingsState` 保存 `LanguagePref`，`App` 持有解析后的 `lang`；错误在 UI 边界按当前语言渲染。

**Tech Stack:** Rust 2024 / iced 0.13 / serde_json（已有依赖，无新增依赖）

**规格：** `docs/superpowers/specs/2026-10-28-i18n-design.md`

**提交策略：** 按用户的长期偏好，未经明确要求不自动提交。每个任务以「测试通过 + diff 审查」作为检查点；如果用户在本轮授权提交，再使用每个任务给出的提交信息。

**通用约定：**

- `tr` / `tr_args` / `tr_plural` / `tr_plural_args` 的 key 必须写成字符串字面量，并紧跟在调用标记之后（200 字符内），便于 Task 13 的源码扫描测试；允许跨行。
- 视图里用 `app.tr(...)` / `app.tr_args(...)` / `app.tr_plural(...)` / `app.tr_plural_args(...)`。
- 拿不到 `App` 的纯函数显式接收 `lang: crate::i18n::Lang`。
- 目录 JSON 的 key 按字母序，值不得为空；每次新增 key 必须同时写入 `zh-CN.json` 与 `en-US.json`。

- [ ] **Step 4: 实现 i18n 模块**

把以下实现写在 `crates/ui/src/i18n/mod.rs` 的测试模块之前：

```rust
use std::collections::HashMap;
use std::sync::OnceLock;

pub mod errors;

#[derive(Debug)]
pub struct Language {
    pub code: &'static str,
    pub native_name: &'static str,
    catalogue: &'static str,
}

impl PartialEq for Language {
    fn eq(&self, other: &Self) -> bool {
        self.code == other.code
    }
}

impl Eq for Language {}

pub type Lang = &'static Language;

pub const ZH_CN: Language = Language {
    code: "zh-CN",
    native_name: "简体中文",
    catalogue: include_str!("../../locales/zh-CN.json"),
};

pub const EN_US: Language = Language {
    code: "en-US",
    native_name: "English",
    catalogue: include_str!("../../locales/en-US.json"),
};

pub const LANGUAGES: &[Language] = &[ZH_CN, EN_US];
pub const FALLBACK: Lang = &EN_US;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum LanguagePref {
    #[default]
    Auto,
    Fixed(Lang),
}

impl LanguagePref {
    pub fn from_setting(value: Option<&str>) -> Self {
        match value.and_then(language_by_code) {
            Some(lang) => Self::Fixed(lang),
            None => Self::Auto,
        }
    }

    pub fn as_setting(self) -> &'static str {
        match self {
            Self::Auto => "auto",
            Self::Fixed(lang) => lang.code,
        }
    }

    pub fn resolve(self) -> Lang {
        match self {
            Self::Auto => detect_system_language(),
            Self::Fixed(lang) => lang,
        }
    }
}

pub fn language_by_code(code: &str) -> Option<Lang> {
    LANGUAGES
        .iter()
        .find(|lang| lang.code.eq_ignore_ascii_case(code))
}

pub fn detect_system_language() -> Lang {
    for var in ["LANGUAGE", "LC_ALL", "LC_MESSAGES", "LANG"] {
        let Ok(raw) = std::env::var(var) else {
            continue;
        };
        for tag in raw.split(':') {
            if let Some(lang) = language_from_tag(tag) {
                return lang;
            }
        }
    }
    FALLBACK
}

fn language_from_tag(raw: &str) -> Option<Lang> {
    let base = raw
        .split(['.', '@'])
        .next()
        .unwrap_or("")
        .replace('_', "-");
    if base.is_empty() || base.eq_ignore_ascii_case("C") || base.eq_ignore_ascii_case("POSIX") {
        return None;
    }
    if let Some(lang) = language_by_code(&base) {
        return Some(lang);
    }
    let primary = base.split('-').next().unwrap_or("").to_ascii_lowercase();
    let code = match primary.as_str() {
        "zh" => "zh-CN",
        "en" => "en-US",
        _ => return None,
    };
    language_by_code(code)
}

fn catalogues() -> &'static HashMap<&'static str, &'static HashMap<String, String>> {
    static CATALOGUES: OnceLock<HashMap<&'static str, &'static HashMap<String, String>>> =
        OnceLock::new();
    CATALOGUES.get_or_init(|| {
        LANGUAGES
            .iter()
            .map(|lang| {
                let map: &'static HashMap<String, String> =
                    Box::leak(Box::new(parse_catalogue(lang.catalogue, lang.code)));
                (lang.code, map)
            })
            .collect()
    })
}

fn parse_catalogue(raw: &str, code: &str) -> HashMap<String, String> {
    match serde_json::from_str(raw) {
        Ok(map) => map,
        Err(error) => {
            tracing::error!(%error, language = code, "embedded locale catalogue is invalid");
            HashMap::new()
        }
    }
}

fn lookup(lang: Lang, key: &str) -> Option<&'static str> {
    catalogues()
        .get(lang.code)?
        .get(key)
        .map(String::as_str)
}

pub fn tr(lang: Lang, key: &'static str) -> &'static str {
    lookup(lang, key)
        .or_else(|| lookup(FALLBACK, key))
        .unwrap_or(key)
}

pub fn tr_args(lang: Lang, key: &'static str, args: &[(&str, &str)]) -> String {
    let mut out = tr(lang, key).to_owned();
    for (name, value) in args {
        out = out.replace(&format!("{{{name}}}"), value);
    }
    out
}

pub fn tr_plural(lang: Lang, one: &'static str, other: &'static str, n: u64) -> &'static str {
    tr(lang, if n == 1 { one } else { other })
}

pub fn tr_plural_args(
    lang: Lang,
    one: &'static str,
    other: &'static str,
    n: u64,
    args: &[(&str, &str)],
) -> String {
    tr_args(lang, if n == 1 { one } else { other }, args)
}
```

```rust
pub fn pick(intent: DialogIntent, lang: crate::i18n::Lang) -> Task<Message> {
    Task::perform(
        async move {
            match tokio::task::spawn_blocking(move || dialog_impl(intent, lang)).await {
                Ok(path) => Some((intent, path)),
                Err(_) => None,
            }
        },
        move |result| match result {
            Some((intent, path)) => Message::DialogResult { intent, path },
            None => Message::Error(crate::i18n::tr(lang, "dialogs.error.failed").to_owned()),
        },
    )
}

fn dialog_impl(intent: DialogIntent, lang: crate::i18n::Lang) -> Option<std::path::PathBuf> {
    let dialog = rfd::FileDialog::new();
    match intent {
        DialogIntent::PickExe => dialog
            .add_filter(crate::i18n::tr(lang, "dialogs.filter.windows"), &["exe"])
            .pick_file(),
        DialogIntent::PickCover => dialog
            .add_filter(crate::i18n::tr(lang, "dialogs.filter.cover"), &["png", "jpg", "jpeg", "webp", "bmp"])
            .pick_file(),
        // 其余分支不变
        _ => dialog.pick_folder(),
    }
}
```

```rust
fn session_label(lang: crate::i18n::Lang, session: application::SessionType) -> &'static str {
    match session {
        application::SessionType::Wayland => "Wayland",
        application::SessionType::X11 => "X11",
        application::SessionType::Unknown => crate::i18n::tr(lang, "app.session.unknown"),
    }
}

fn default_runner_label(app: &App) -> &str {
    app.settings
        .default_runner_id
        .and_then(|id| app.runners.iter().find(|runner| runner.id == id))
        .map(|runner| runner.name.as_str())
        .unwrap_or_else(|| app.tr("launch.no_default_runner"))
}

fn delete_title(app: &App, target: &DeleteTarget) -> String {
    match target {
        DeleteTarget::Game(id) => app
            .games
            .iter()
            .find(|game| game.id == *id)
            .map(|game| app.tr_args("delete.title.game", &[("name", &game.name)]))
            .unwrap_or_else(|| app.tr("delete.title.game_fallback").to_owned()),
        DeleteTarget::Runner(id) => app
            .runners
            .iter()
            .find(|runner| runner.id == *id)
            .map(|runner| app.tr_args("delete.title.runner", &[("name", &runner.name)]))
            .unwrap_or_else(|| app.tr("delete.title.runner_fallback").to_owned()),
        DeleteTarget::Prefix { path, .. } => app.tr_args(
            "delete.title.prefix",
            &[("path", &path.display().to_string())],
        ),
    }
}

fn delete_body(lang: crate::i18n::Lang, target: &DeleteTarget) -> &'static str {
    match target {
        DeleteTarget::Game(_) => crate::i18n::tr(lang, "delete.body.game"),
        DeleteTarget::Runner(_) => crate::i18n::tr(lang, "delete.body.runner"),
        DeleteTarget::Prefix { .. } => crate::i18n::tr(lang, "delete.body.prefix"),
    }
}
```

```rust
#[test]
fn keys_used_in_source_exist() {
    let root = std::path::Path::new(env!("CARGO_MANIFEST_DIR")).join("src");
    let mut missing = Vec::new();
    for file in rust_files(&root) {
        let source = std::fs::read_to_string(&file).expect("read source file");
        for key in keys_in(&source) {
            if lookup(&ZH_CN, &key).is_none() || lookup(&EN_US, &key).is_none() {
                missing.push(format!("{}: {key}", file.display()));
            }
        }
    }
    assert!(
        missing.is_empty(),
        "missing or partially translated keys:\n{}",
        missing.join("\n")
    );
}

fn rust_files(dir: &std::path::Path) -> Vec<std::path::PathBuf> {
    let mut files = Vec::new();
    for entry in std::fs::read_dir(dir).expect("read source dir") {
        let path = entry.expect("dir entry").path();
        if path.is_dir() {
            files.extend(rust_files(&path));
        } else if path.extension().is_some_and(|ext| ext == "rs") {
            files.push(path);
        }
    }
    files
}

fn keys_in(source: &str) -> Vec<String> {
    let bytes = source.as_bytes();
    let mut keys = Vec::new();
    let mut index = 0;
    while index < bytes.len() {
        if bytes[index] != b'"' {
            index += 1;
            continue;
        }
        let start = index + 1;
        let mut end = start;
        while end < bytes.len() && bytes[end] != b'"' {
            end += if bytes[end] == b'\\' { 2 } else { 1 };
        }
        if end >= bytes.len() {
            break;
        }
        if let Ok(literal) = std::str::from_utf8(&bytes[start..end]) {
            if looks_like_key(literal) && preceded_by_tr_marker(source, index) {
                keys.push(literal.to_owned());
            }
        }
        index = end + 1;
    }
    keys
}

const TR_MARKERS: &[&str] = &["tr(", "tr_args(", "tr_plural(", "tr_plural_args("];

fn preceded_by_tr_marker(source: &str, quote: usize) -> bool {
    let mut begin = quote.saturating_sub(200);
    while begin > 0 && !source.is_char_boundary(begin) {
        begin -= 1;
    }
    let before = &source[begin..quote];
    TR_MARKERS.iter().any(|marker| before.contains(marker))
}

const KEY_NAMESPACES: &[&str] = &[
    "app.", "choices.", "common.", "delete.", "detail.", "dialogs.", "draft.", "errors.",
    "launch.", "library.", "logs.", "nav.", "runners.", "settings.", "time.", "widgets.",
];

fn looks_like_key(value: &str) -> bool {
    !value.is_empty()
        && KEY_NAMESPACES
            .iter()
            .any(|namespace| value.starts_with(namespace))
        && value.bytes().all(|b| {
            b.is_ascii_lowercase() || b.is_ascii_digit() || matches!(b, b'.' | b'_' | b'-')
        })
}
```

```markdown
# 多语言维护指南

界面语言由 `crates/ui/src/i18n` 提供，语言目录位于 `crates/ui/locales/<code>.json`，
编译期通过 `include_str!` 嵌入二进制。

## 目录格式

- 扁平 JSON 对象，key 为点分小写字符串，value 为文案。
- key 按字母序排列，值不得为空。
- 占位符写作 `{name}`，由 `tr_args` 替换；同一 key 在各语言中的占位符集合必须一致。
- 复数使用双 key：`*.one` / `*.other`，由 `tr_plural` / `tr_plural_args` 选择。
  中文两条取相同文案；超过两种复数形式的语言需要先扩展本机制。

## 命名空间

`common.*` 通用按钮，`nav.*` 侧边栏，`library.*` / `detail.*` / `runners.*` / `logs.*` /
`settings.*` 按页面，`choices.*` 下拉选项，`dialogs.*` 文件对话框，`draft.*` 表单校验，
`delete.*` 删除确认，`errors.*` 应用层错误，`time.*` 时间文案。

## 新增语言

1. 复制 `crates/ui/locales/en-US.json` 为 `crates/ui/locales/<code>.json`，翻译 value，
   保持 key 不变。
2. 在 `crates/ui/src/i18n/mod.rs` 增加 `Language` 常量，并加入 `LANGUAGES`。
3. 如果系统语言 tag 需要特殊映射（如 `ja` → `ja-JP`），在 `language_from_tag` 增加一条
   映射；仅当 tag 无法通过「主语言前缀 == code 前缀」匹配时才需要。
4. 运行 `cargo test -p ui`，确保 key 集合、占位符、源码 key 扫描全部通过。
5. 手动检查：两种主题下切换新语言，走查游戏库、详情、Runner、设置、日志、删除确认，
   确认没有空白文字、溢出或截断异常。

## 回退规则

所选语言缺少 key → `en-US` → key 本身。设置值缺失或未知 → `auto`，再按
`LANGUAGE → LC_ALL → LC_MESSAGES → LANG` 探测；无法识别时使用 English。

## 范围

底层技术错误（Wine、sqlite、IO 原文）与日志正文不翻译，只翻译分类标签与界面文案。
```
