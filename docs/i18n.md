# 多语言维护指南

界面语言由 `crates/ui/src/i18n` 提供，语言目录位于 `crates/ui/locales/<code>.json`，
编译期通过 `include_str!` 嵌入二进制。

## 目录格式

- 扁平 JSON 对象，key 为点分小写字符串，value 为文案。
- key 按字母序排列，值不得为空。
- 占位符写作 `{name}`，由 `tr_args` 替换；同一 key 在各语言中的占位符集合必须一致。
- 复数使用双 key：`*.one` / `*.other`，由 `tr_plural` / `tr_plural_args` 选择。
  中文两条取相同文案；超过两种复数形式的语言需要先扩展本机制。

## 命名空间

`common.*` 通用按钮，`nav.*` 侧边栏，`library.*` / `detail.*` / `runners.*` / `logs.*` /
`settings.*` 按页面，`choices.*` 下拉选项，`dialogs.*` 文件对话框，`draft.*` 表单校验，
`delete.*` 删除确认，`errors.*` 应用层错误，`time.*` 时间文案。

## 新增语言

1. 复制 `crates/ui/locales/en-US.json` 为 `crates/ui/locales/<code>.json`，翻译 value，
   保持 key 不变。
2. 在 `crates/ui/src/i18n/mod.rs` 增加 `Language` 常量，并加入 `LANGUAGES`。
3. 如果系统语言 tag 需要特殊映射（如 `ja` → `ja-JP`），在 `language_from_tag` 增加一条
   映射；仅当 tag 无法通过「主语言前缀 == code 前缀」匹配时才需要。
4. 运行 `cargo test -p ui`，确保 key 集合、占位符、源码 key 扫描全部通过。
5. 手动检查：两种主题下切换新语言，走查游戏库、详情、Runner、设置、日志、删除确认，
   确认没有空白文字、溢出或截断异常。

## 回退规则

所选语言缺少 key → `en-US` → key 本身。设置值缺失或未知 → `auto`，再按
`LANGUAGE → LC_ALL → LC_MESSAGES → LANG` 探测；无法识别时使用 English。

## 范围

底层技术错误（Wine、sqlite、IO 原文）与日志正文不翻译，只翻译分类标签与界面文案。
